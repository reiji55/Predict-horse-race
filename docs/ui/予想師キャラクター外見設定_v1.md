# 予想師キャラクター 外見設定 v1

画像生成AIに投げる際のプロンプト素材として使えるように、各キャラの外見を言語化。
「モチーフにしたいイラスト」がある場合は、雰囲気の参考程度に留め、そっくり模写にはしない方が安全(著作権)。

共通ルール:
- 全員バストアップ〜上半身。丸みのあるアイコン向けの構図
- 表情はキャラの性格が一目で伝わることを最優先
- 配色は各カードのブランドカラーとリンクさせる(低=緑、中=金土色、高=赤、確変=金)

---

## 🧑‍🎓 低リスク: 数理院生 ケイ

**属性**: 都内有名大学・数学科の大学院生。20代前半〜半ば。

- **体型/年齢感**: 細身、色白、いかにも室内派
- **髪型**: 少し伸びた黒髪、無造作に触ってセットしてなさそうな感じ。前髪長め
- **服装**: 白シャツかグレーのパーカー。首から下げた大学の学生証やスマホのストラップ。腕にシャープペンor鉛筆
- **小物**: 分厚い統計学の本、ノートPC、または手元にびっしり数式を書いたノート
- **表情**: 目を細めて集中している、あるいは小さく満足げに微笑む「解けた」の瞬間の顔
- **色調**: 緑系(カードカラーと連動)。落ち着いた寒色で統一、派手さは出さない
- **雰囲気の参考ワード**: 「理系大学院生」「オタク気質だが清潔感」「静かな自信」

## 👨‍👧 中リスク: 週末の馬券パパ 哲さん

**属性**: 40代前半、サラリーマン、既婚・子持ち。

- **体型/年齢感**: 中肉中背、少しお腹が出始めている、疲れが顔に出てるけど目は優しい
- **髪型**: 短髪、少し後退気味、または七三分け
- **服装**: 休日らしいポロシャツかチェックシャツ、季節によってウィンドブレーカー。競馬場の入場者リストバンドを腕につけている
- **小物**: 出馬表とペン(耳に挟んでいてもいい)、片手に子どもと繋いでいた名残の小さな手袋や、缶コーヒー
- **表情**: 温かい笑顔、でもちょっと眠そうな目元。子どもに「またここー?」と言われて苦笑いしてそうな空気感
- **色調**: 金土色〜アンバー系(カードカラーと連動)。親しみやすい暖色
- **雰囲気の参考ワード**: 「休日のお父さん」「気のいい近所のおじさん」「疲れてるけど幸せそう」

## 👴 高リスク: ベレー帽の大穴師 源さん

**属性**: 60代後半〜70代、独身らしき雰囲気、素性不明の生粋のギャンブラー。

- **体型/年齢感**: 小柄で痩せ型、日焼けした肌、しわが多い
- **髪型**: 白髪混じりの無精髭、ベレー帽から覗く白髪
- **服装**: **トレードマークのベレー帽(濃紺かカーキ)**。着古したジャンパーかベスト、色あせたマフラー。全体的に「小汚い」が愛嬌がある
- **小物**: 丸めた新聞紙(出馬表)を小脇に挟む、指の間に挟んだ煙草(演出上は吸ってる描写を避け、くわえていない状態でもOK)、外れ馬券が数枚ポケットからはみ出てる
- **表情**: ニヤッとした笑み、片目をすがめてる、口を開けて笑ってる(ヤジってる)ようなダイナミックな表情
- **色調**: 赤系(カードカラーと連動)、くすんだ色合いでくたびれ感を出す
- **雰囲気の参考ワード**: 「昭和の競馬場名物おじさん」「愛すべき偏屈」「熱量が服からはみ出てる」

## 🎩 確変: 伝説の予想師 鳳(オオトリ)

**属性**: 年齢不詳、性別不詳でもいいくらいの謎の存在感。

- **体型/年齢感**: すらっとした長身シルエット。逆光や影で顔の詳細をあえて見せない演出もアリ
- **髪型**: 整えられた髪、あるいは帽子で髪自体が見えない
- **服装**: **シルクハットまたは上質なハンチング帽**、仕立ての良いロングコートかジャケット、金の懐中時計やカフスボタンなどブランドを感じさせる小物。手袋
- **小物**: 札束をさりげなく持つ手、あるいは杖。競馬新聞ではなく万年筆で何かにサインしているような余裕
- **表情**: 口元だけ薄く笑う、目元は帽子の影で隠れ気味。「多くを語らない」雰囲気
- **色調**: 金×黒のコントラスト(確変カードカラーと連動)。豪華だが下品にならない上質な金
- **雰囲気の参考ワード**: 「ダンディ」「都市伝説」「一度見たら忘れられないシルエット」

## 画像生成プロンプトの組み立て例(参考)

```
[スタイル指定], upper body portrait, [キャラの外見特徴],
[表情], [服装], [色調], simple background, character icon style
```

スタイル(タッチ)は「モチーフにしたいイラスト」の雰囲気を **抽象的な言葉で** 添えるのがおすすめです。
例: 「劇画調」「ゆるいタッチの日本のイラスト」「浮世絵版画風」など、作風の特徴を言語化して伝える形なら、特定の作品の模写にならず安全に寄せられます。
