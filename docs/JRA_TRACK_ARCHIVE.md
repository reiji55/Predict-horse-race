# JRAの含水率・クッション値（過去分）

予想ロジック（`logic/`）は**まだ使わない**。過去分をそろえて、オッズを使わない3着内確率の式に足して効くかを検証する。

## 何を集めるか

JRA公式の「含水率・クッション値（馬場情報）」の過去データ。年ごとのページ（`https://www.jra.go.jp/keiba/baba/archive/{年}.html`）から、開催ごとのPDFを読む。

- 含水率：2018年7月27日から（芝・ダートの、ゴール前と4コーナー）
- 芝のクッション値：2020年9月11日から
- 使用コース（A〜D）
- 測るのは原則として開催日の早朝（金曜は午前）。その日のレースより前に分かる情報

## 保存先

`data/track/jra_track_archive.csv`（1日1行）

| 列 | 中身 |
|---|---|
| year / venue / kai / day_no | 年・競馬場・回・開催日次（金曜の測定は日次なし） |
| date / weekday | 測定日・曜日 |
| course | 使用コース（A〜D） |
| cushion_time / cushion | クッション値の測定時刻・値（2020年9月より前は空） |
| moisture_time | 含水率の測定時刻 |
| turf_goal / turf_turn4 / dirt_goal / dirt_turn4 | 含水率（%）。測っていない日は空 |
| source | 読んだPDFのURL |

PDFそのものは保存しない（数値だけ）。

## 動かし方

Actions 画面の「**JRA馬場データの過去分（手動）**」（`manual_jra_track_archive.yml`）を実行する。
約300ファイルで、間隔は3〜5秒なので20分ほど。結果はコミットされる。

PRでは3ファイルだけ読み、1行目（2025年1回中山 1月4日：B 10:30 10.1 10:30 13.4 13.7 2.1 2.1）が正しく読めるかをPRにコメントする。

## 今週分
