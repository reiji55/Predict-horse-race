## 結論

1. **本線（`edge-v0` の近似 M-x_out_2）を上回る作り方は無かった。** 計画 §5 の基準（本線との差の区間の下限が 0 を超える）を満たす候補は0件。計画どおり、確かめる期間（2022-01〜2026-10-04）は計算しない。`edge-v0` は本線のまま。
2. **試した7つの作り方の中では、M-x_out_2 の回収率が最も高かった**（0.792）。市場の人気上位5組をそのまま買う P-5（0.764）、上位10組の P-10、1頭の露出を3点までにする M-cap3 は、本線より有意に低かった。ただし、どれも払戻率（0.75）をわずかに越える程度で、100%には遠い。
3. **探す期間では、3連複の人気薄の組ほど回収率が低かった**（H-026）。人気順1〜20位の組はおよそ 0.75〜0.78 で払戻率と同じくらいだが、51〜100位は 0.68、101〜200位は 0.62、201位以下は 0.44 だった。区間を付けていない記述で、この期間・このデータ・確定オッズに限った傾向。
4. **探す期間では、11R の回収率が他のレースより低かった。** M-x_out_2 は 11R で 0.712、11R 以外で 0.799。P-5 は 11R で 0.656 だった。ただし、11R と11R以外の差そのものの区間は計算しておらず（それぞれを全レースの本線と比べただけ）、他の期間でも確かめていない。この期間・このデータ・確定オッズに限った記述的な傾向として扱う。

## ここから言えること・言えないこと

- 言えること：探す期間で、市場の確定オッズだけで組んだ7通りの券は、回収率がおよそ0.74〜0.79に収まった。今の本線の近似はその中で一番良い側にあった。人気薄の組を多く含む券ほど不利という傾向も見えた（H-026。H-024 の v1 の券も人気薄を含む）。どれも、この期間・このデータ・確定オッズに限った記述で、確かめる期間では測っていない。
- 言えないこと：確定オッズで選んでいるので、発走前のオッズで選ぶ実際の券の成績は、これより悪いかもしれない。3連複のオッズ表が無いので、3連複の市場そのものが組ごとにずれているか（H-025）は確かめていない。
- 回収率100%を越える材料は、確定の市場の中には見つからなかった。次は、発走前と確定の差（締め切り前の売れ方、H-012）と、3連複のオッズ表を使う券種どうしのずれ（H-025）を、前向きの記録で調べる（EDGE_LOOP.md §8.1）。
