# チャット実験のルール（ひな形）

下の「ここから」以降を写して埋め、`data/chat_experiments/{experiment_id}/rule_v1.md` として**最初のレースより前に**コミットします。
コミットしたあとは書き換えません。変えるときは `rule_v2.md` を新しく足します（v1 と v2 の集計は混ざりません）。
使い方の全体: `CHAT_EXPERIMENTS.md`

書くときの注意:
- 別の人（別のチャット）が読んでも、同じ馬を同じ枠に入れ、同じ買い目になるくらい具体的に書きます。
- 数値の境目（何番手以内、何秒差以内、何走以上など）と、同点・迷ったときの決め方を書きます。
- 枠のラベルは、記録の `frames`・`frame_tag` にそのまま書く文字列です。短く、ほかのラベルと紛れないものにします。

---（ここから）---
