# 3着以内の確率の式（予想チャット用・手で使える版）

週末3CARDS の検証（2010〜2026年のJRA平地 約5.6万レース）から作った、各馬の **1着の確率** と **3着以内の確率** を出す式です。
**オッズと人気は一切使いません。** netkeiba の出馬表と「過去5走」ページに載っている数字だけで計算できます。

## 1. どのくらい当たるか（2024〜2026年・8頭立て以上の8,951レース。式づくりには使っていない期間）

| | 1位の馬が3着以内 | 上位5頭に3着以内の3頭がそろう | 上位6頭にそろう |
|---|---|---|---|
| **この式（手で使える版）** | 57.2% | 28.0% | 40.4% |
| 本命の式（データベースで動かす版。ここでは動かせない） | 63.3% | 33.0% | 45.5% |
| 人気順（参考） | 65.4% | 36.1% | 49.6% |

メインレース（11R）だけだと、この式は 1位 49.9%・上位5頭にそろう 19.3%（人気順 57.1%・24.2%）。

式の順位ごとの実際の3着内率（この式）：

| 式の順位 | 1位 | 2位 | 3位 | 4位 | 5位 | 6位 | 7位 | 8位 | 9位 | 10位以下 |
|---|---|---|---|---|---|---|---|---|---|---|
| 3着内率 | 57% | 46% | 39% | 33% | 27% | 22% | 18% | 15% | 12% | 6%前後 |

確率の数字は「降水確率」と同じ読み方です。20%と出た馬を100頭集めると、だいたい20頭が3着以内に来ます（2024〜2026年で確認済み）。
上位5頭の外から3着以内の馬が出るレースは約7割あるので、上位5頭は「当確」ではなく「確率の高い順」と読んでください。

## 2. 式

各馬の **強さスコア** s を、材料の「標準化した値」z の重みつきの和で出します。

```
z_k = (材料kの値 − 平均_k) ÷ 標準偏差_k     （−4〜+4で打ち切り。値が無ければ z=0＝平均扱い）
s   = Σ β_k × z_k
P(1着)          = e^s ÷ Σ(全馬の e^s)
P(2着 | 1着が決まった後) = e^(0.9918·s) ÷ Σ(残りの馬の e^(0.9918·s))
P(3着 | 1・2着が決まった後) = e^(0.8781·s) ÷ Σ(残りの馬の e^(0.8781·s))
P(3着以内)      = その馬が1・2・3着になるすべての並びの確率の合計
```

同じ計算で、2頭・3頭の組がそろって3着以内に入る確率（ワイド・3連複の確率）も出ます（下のコードが計算します）。

### 材料・重み（β は標準偏差1つ分あたり。大きい順）

| 材料 | 定義（netkeibaで見る場所） | β | 平均 | 標準偏差 |
|---|---|---|---|---|
| クラスの下がり幅 | 直近5走の平均クラス − 今回のクラス。クラスの数字：新馬0・未勝利1・1勝2・2勝3・3勝4・OP/L 5・G3 6・G2 7・G1 8 | **+0.380** | −0.403 | 0.841 |
| 直近5走の着順率の平均 | 着順率 =（着順−1）÷（頭数−1）。0=1着、1=最下位 | **−0.295** | 0.453 | 0.217 |
| 年齢 | 出馬表 | **−0.258** | 3.570 | 1.306 |
| 騎手の複勝率 | 騎手の3着内率（netkeibaの騎手ページの年度成績でよい。25%なら0.25） | **+0.235** | 0.212 | 0.089 |
| 前走の着順率 | 同上（前走だけ） | **−0.231** | 0.473 | 0.305 |
| 直近5走の着差の平均 | 勝ち馬との着差（秒）。勝った走は0、3秒以上は3（過去5走の勝ち馬欄のカッコ内） | **−0.229** | 1.109 | 0.691 |
| 調教師の複勝率 | 調教師の3着内率 | +0.154 | 0.212 | 0.064 |
| 同じ条件での好走数 | 直近5走のうち、今回と同じ芝ダで距離差200m以内のレースで3着以内だった回数 | +0.143 | 0.763 | 1.071 |
| 前走の着差 | 前走の勝ち馬との着差（秒、0〜3） | −0.128 | 1.137 | 0.899 |
| 斤量（レース平均との差） | 斤量 − このレースの平均斤量（kg）。強い馬ほど重い斤量を背負うためプラス | +0.105 | 0.000 | 1.258 |
| 斤量（いつもとの差） | 斤量 − その馬の直近5走の平均斤量（kg） | −0.093 | 0.140 | 1.235 |
| 半年以上の休み明け | 前走から180日以上なら1 | −0.075 | 0.038 | 0.190 |
| 4角位置の平均 | 直近5走の（通過順の最後の数字 ÷ 頭数）の平均。0に近い＝前で競馬 | −0.072 | 0.482 | 0.212 |
| 距離変更 | |今回の距離 − 前走の距離|（m） | −0.025 | 153.5 | 185.2 |
| 休養日数 | ln(1 + 前走からの日数) | −0.019 | 3.629 | 0.814 |
| 直近5走の3着以内の回数 | 0〜5（ほかの材料と重なるので重みは小さい） | −0.015 | 1.060 | 1.184 |
| 馬体重の増減 | |当日の増減|（kg） | −0.012 | 4.453 | 4.573 |
| 馬番の位置 | （馬番−1）÷（頭数−1） | −0.002 | 0.535 | 0.325 |

読み方：プラスの材料は大きいほど有利、マイナスの材料は大きいほど不利です。
たとえば「格上のクラスで走ってきた（クラスの下がり幅が大きい）」「近走の着順・着差が良い」「若い」「騎手・厩舎の複勝率が高い」「同じ条件で好走している」馬ほど、強さスコアが上がります。

## 3. 計算コード（Python。コードを実行できるチャットにそのまま貼れます）

1頭ごとに、今回の情報と過去5走（新しい順）を入れると、1着・3着以内の確率と、確率の高い組み合わせを出します。

```python
import itertools, math

BETA = {  # 材料: (β, 平均, 標準偏差)
    'margin_mean5': (-0.2293, 1.1092, 0.6914), 'margin_last': (-0.1276, 1.1374, 0.8986),
    'last_finish_pct': (-0.2311, 0.4730, 0.3047), 'fin_pct_mean5': (-0.2949, 0.4532, 0.2167),
    'top3_cnt5': (-0.0154, 1.0595, 1.1837), 'sameband_top3': (+0.1432, 0.7627, 1.0710),
    'cls_drop5': (+0.3799, -0.4033, 0.8407), 'pos4_pct_mean5': (-0.0723, 0.4819, 0.2121),
    'jky_top3': (+0.2349, 0.2119, 0.0888), 'trn_top3': (+0.1536, 0.2123, 0.0640),
    'age': (-0.2582, 3.5703, 1.3058), 'impost_rel': (+0.1054, 0.0, 1.2575),
    'impost_vs_own': (-0.0930, 0.1402, 1.2346), 'log_days_off': (-0.0187, 3.6285, 0.8139),
    'long_rest': (-0.0751, 0.0377, 0.1904), 'dist_change_abs': (-0.0252, 153.4584, 185.1980),
    'weight_change_abs': (-0.0115, 4.4532, 4.5734), 'gate_pct': (-0.0021, 0.5349, 0.3249),
}
G2, G3 = 0.9918, 0.8781
CLASS = {'新馬': 0, '未勝利': 1, '1勝': 2, '2勝': 3, '3勝': 4, 'OP': 5, 'L': 5, 'G3': 6, 'G2': 7, 'G1': 8}


def features(h, race):
    """h: 1頭分。race: 今回のレース（頭数・芝ダ・距離・クラス・平均斤量）。値が無い材料は入れない（＝平均扱い）。"""
    past = h.get('past', [])[:5]           # 新しい順。各走 {'finish','heads','margin','cls','surf','dist','pos4','impost','days_ago'}
    f = {'age': h['age'], 'jky_top3': h.get('jockey_top3'), 'trn_top3': h.get('trainer_top3'),
         'impost_rel': h['impost'] - race['avg_impost'],
         'gate_pct': (h['number'] - 1) / max(race['heads'] - 1, 1)}
    if h.get('weight_change') is not None:
        f['weight_change_abs'] = abs(h['weight_change'])
    fin = [(p['finish'] - 1) / max(p['heads'] - 1, 1) for p in past if p.get('finish')]
    mg = [0.0 if p.get('finish') == 1 else min(max(p.get('margin', 3.0), 0), 3) for p in past if p.get('finish')]
    if fin:
        f['last_finish_pct'], f['fin_pct_mean5'] = fin[0], sum(fin) / len(fin)
        f['margin_last'], f['margin_mean5'] = mg[0], sum(mg) / len(mg)
        f['top3_cnt5'] = sum(1 for p in past if p.get('finish') and p['finish'] <= 3)
        f['sameband_top3'] = sum(1 for p in past if p.get('finish') and p['finish'] <= 3
                                 and p['surf'] == race['surf'] and abs(p['dist'] - race['dist']) <= 200)
    cl = [CLASS[p['cls']] for p in past if p.get('cls') in CLASS]
    if cl:
        f['cls_drop5'] = sum(cl) / len(cl) - CLASS[race['cls']]
    p4 = [p['pos4'] / p['heads'] for p in past if p.get('pos4') and p.get('heads')]
    if p4:
        f['pos4_pct_mean5'] = sum(p4) / len(p4)
    imp = [p['impost'] for p in past if p.get('impost')]
    if imp:
        f['impost_vs_own'] = h['impost'] - sum(imp) / len(imp)
    if past and past[0].get('days_ago') is not None:
        d = past[0]['days_ago']
        f['log_days_off'], f['long_rest'] = math.log1p(d), 1.0 if d >= 180 else 0.0
    if past and past[0].get('dist'):
        f['dist_change_abs'] = abs(race['dist'] - past[0]['dist'])
    return f


def strength(f):
    s = 0.0
    for k, (b, m, sd) in BETA.items():
        if f.get(k) is not None:
            s += b * max(-4, min(4, (f[k] - m) / sd))
    return s


def probabilities(horses, race):
    s = {h['number']: strength(features(h, race)) for h in horses}
    n = list(s)
    e1 = {i: math.exp(s[i]) for i in n}; e2 = {i: math.exp(G2 * s[i]) for i in n}; e3 = {i: math.exp(G3 * s[i]) for i in n}
    T1, T2, T3 = sum(e1.values()), sum(e2.values()), sum(e3.values())
    win = {i: e1[i] / T1 for i in n}
    top3 = {i: 0.0 for i in n}; trio = {}
    for a in n:
        pa = e1[a] / T1
        for b in n:
            if b == a: continue
            pb = pa * e2[b] / (T2 - e2[a])
            for c in n:
                if c in (a, b): continue
                p = pb * e3[c] / (T3 - e3[a] - e3[b])
                for x in (a, b, c): top3[x] += p
                key = tuple(sorted((a, b, c))); trio[key] = trio.get(key, 0) + p
    wide = {}
    for k, p in trio.items():
        for pair in itertools.combinations(k, 2): wide[pair] = wide.get(pair, 0) + p
    return s, win, top3, trio, wide


# 使い方の例（数字はダミー）
race = {'heads': 3, 'surf': 'ダ', 'dist': 1800, 'cls': 'OP', 'avg_impost': 57.0}
horses = [
    {'number': 1, 'age': 4, 'impost': 57, 'jockey_top3': 0.30, 'trainer_top3': 0.25, 'weight_change': 2,
     'past': [{'finish': 2, 'heads': 16, 'margin': 0.1, 'cls': '3勝', 'surf': 'ダ', 'dist': 1800, 'pos4': 3,
               'impost': 57, 'days_ago': 35}]},
    {'number': 2, 'age': 6, 'impost': 58, 'jockey_top3': 0.18, 'trainer_top3': 0.20,
     'past': [{'finish': 9, 'heads': 16, 'margin': 1.2, 'cls': 'OP', 'surf': 'ダ', 'dist': 1900, 'pos4': 12,
               'impost': 58, 'days_ago': 28}]},
    {'number': 3, 'age': 5, 'impost': 56, 'jockey_top3': 0.22, 'trainer_top3': 0.21, 'past': []},
]
s, win, top3, trio, wide = probabilities(horses, race)
for i in sorted(top3, key=top3.get, reverse=True):
    print(f'{i}番  強さ{s[i]:+.2f}  1着{win[i]:.1%}  3着以内{top3[i]:.1%}')
print('3連複の確率 上位:', sorted(trio.items(), key=lambda x: -x[1])[:5])
print('ワイドの確率 上位:', sorted(wide.items(), key=lambda x: -x[1])[:5])
```

18頭立てでも数秒で終わります。過去5走の数字は、出馬表の「過去5走」タブ（着順・頭数・勝ち馬との差・クラス・コース・通過順・斤量・日付）から拾えます。
騎手・調教師の複勝率が分からない場合は入れなくて構いません（平均扱いになります）。

## 4. 検証で分かったこと（式に足すと当たりが良くなった材料。手の版には入れていない）

本命の式には入っていて、手の版には入れていない材料です。予想のときの「上乗せ・割り引き」の参考にしてください（どれも2023年までで見つけ、2024〜2026年で同じ向きに効くことを確認）。

- **展開の有利不利を差し引いた過去走**：前走（直近数走）で「位置取りのわりにペースが不利だった馬」は、式の見立てよりよく来る（例：速いペースで前にいた、遅いペースで後ろにいた）。
- **上がりの指数**：過去走の上がり3Fを、同じ競馬場・距離・馬場・前半ペースの「普通の上がり」と比べて速い馬は有利。
- **開催を通した馬場の傾向**：同じ開催の前の日までに、同じコースで前に行った馬・内枠が有利だったなら、今回もその傾向が続きやすい。
- **小さく効く**：東西の輸送、左右回りの巧拙、開催の何日目か。
- **効かなかった**：今回の相手との直接対決、騎手の当日の調子、休み明けから何戦目か、展開（ペース）予想そのもの（レース全体のペースが分かっていても当たりはほとんど変わらない）。

## 5. 注意

- 手の版は本命の式より当たりが落ちます（1位の3着内率で約6ポイント）。本命の式はデータベース（全馬の16年分の成績）が必要で、チャットでは動かせません。
- 数字は2024〜2026年の平均です。1レースごとの的中を約束するものではありません。
- 新馬戦など過去走が無い馬は、ほとんどの材料が平均扱いになり、年齢・騎手・厩舎・斤量だけで決まります。
