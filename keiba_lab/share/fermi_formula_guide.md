# フェルミ式：掛け算で出す「3着以内の確率」（手で使える版）

週末3CARDS の検証（2011〜2026年のJRA平地 約5万レース）から、帰納的に作った式です。
**オッズと人気は使いません。** netkeiba の出馬表・「過去5走」・調教ページ（無料）で分かる数字だけで計算できます。
作成：2026-11-14（同日、§8〜§11を追加）。倍率は2011〜2023年のレースから決め、当たり具合は2024〜2026年（式づくりに使っていない期間）で測りました。

## 1. 式の形

```
3着以内のオッズ = 基準オッズ × 倍率① × 倍率② × … × 倍率⑬
基準オッズ      = 3 ÷（頭数 − 3）          例：16頭立てなら 3/13 = 0.23
3着以内の確率   = オッズ ÷（1 + オッズ）
```

最後に、全馬の確率の合計がちょうど 3 になるよう、全馬のオッズに同じ数を掛けて調整します（下のコードが自動でやります）。

倍率は「その指数で、この馬はメンバー中の何位か」で表から引きます。同じ値の馬は上の順位にそろえます。

## 3. 計算コード（Python。コードを実行できるチャットに貼れます）

各馬について、①〜⑨は「メンバー中の順位」（出せない馬は None）、⑩〜⑬は値を入れます。

```python
RANK = {  # 1位, 2位, 3位, 4-5位, 6-8位, 9-12位, 13位以下, なし
    'fin5':   [1.13, 1.21, 1.18, 1.13, 1.01, 0.86, 0.67, 0.98],
    'jockey': [1.53, 1.31, 1.18, 1.01, 0.85, 0.75, 0.69, 1.00],
    'prize':  [1.61, 1.41, 1.25, 1.02, 0.81, 0.70, 0.65, 0.98],
    'last':   [1.34, 1.56, 1.32, 1.09, 0.85, 0.68, 0.62, 0.98],
    'class':  [1.15, 1.14, 1.11, 1.06, 0.95, 0.88, 0.82, 0.98],
    'trainer':[1.25, 1.16, 1.06, 0.99, 0.90, 0.89, 0.86, 1.00],
    'margin5':[1.33, 1.27, 1.19, 1.07, 0.92, 0.80, 0.69, 0.97],
    'weight': [1.09, 1.09, 1.08, 1.02, 0.96, 0.93, 0.89, 1.00],
    'last3f': [1.16, 1.05, 1.00, 0.95, 0.90, 0.94, 1.11, 0.97],
}
def by_rank(key, r):
    if r is None: return RANK[key][7]
    i = 0 if r == 1 else 1 if r == 2 else 2 if r == 3 else 3 if r <= 5 else 4 if r <= 8 else 5 if r <= 12 else 6
    return RANK[key][i]
def career(n):  return 0.98 if n == 0 else 0.75 if n <= 2 else 1.05 if n <= 5 else 1.12 if n <= 10 else 1.13 if n <= 20 else 1.06
def rest(d):    return 0.98 if d is None else 1.06 if d <= 14 else 1.23 if d <= 28 else 1.28 if d <= 63 else 1.15 if d <= 120 else 0.91 if d <= 240 else 0.61
def age(a):     return 1.20 if a <= 2 else 1.18 if a == 3 else 1.17 if a == 4 else 1.07 if a == 5 else 0.88 if a == 6 else 0.67
def train(g):   return {'A': 1.68, 'B': 1.15, 'C': 0.82, 'D': 0.68}.get(g, 0.98)

def top3_probabilities(horses, power=1.0):
    """horses: [{'number':1, 'ranks':{'fin5':3,'jockey':1,...}, 'career':12, 'rest':35, 'age':4, 'train':'B'}, ...]
    power: メインレース（11R）は 0.79 を入れる（そのままだと強気すぎるため。§8）。それ以外は 1.0。"""
    n = len(horses)
    odds = {}
    for h in horses:
        o = 3 / max(n - 3, 1)
        for key in RANK: o *= by_rank(key, h['ranks'].get(key))
        o *= career(h['career']) * rest(h.get('rest')) * age(h['age']) * train(h.get('train'))
        odds[h['number']] = o ** power
    k = 1.0
    for _ in range(100):                       # 確率の合計を 3 にそろえる
        k *= min(3, n) / sum(k * o / (1 + k * o) for o in odds.values())
    return {i: k * o / (1 + k * o) for i, o in odds.items()}
```

## 5. 堅さ指数：買いやすいレースを見分ける

式の上位5頭の確率を足した数（最大3）を「堅さ指数」とします。大きいほど、上位5頭で3着以内を独占しやすいレースです。

| 堅さ指数 | レースの割合 | 上位5頭に3頭そろった率 | 1位の馬の3着内率 |
|---|---|---|---|
| 1.9 以下 | 42% | 17% | 49% |
| 1.9〜2.1 | 35% | 27% | 59% |
| 2.1〜2.3 | 16% | 42% | 65% |
| 2.3 超 | 7% | 60% | 72% |

メインレースは多頭数が多く、堅さ指数 1.9 以下が約半分です（そろった率は約10%）。2.1 を超えるメインレースは約2割で、そろった率は約35%でした。

## 6. 検証で分かったこと

- **重要な順**（式に1つずつ足したときに効いた順）：近5走の着順 → 騎手 → 1走あたり賞金 → 前走の着順 → クラス → 調教師 → 着差 → キャリア → 休養 → 馬体重 → 上がり → 年齢。
- **調教評価**は確率を正確にします（A評価の馬は実際に44%が3着以内。評価を入れない式の見立ては37%）。ただし順位の入れ替えはほとんど起きません。
- **効かなかったもの**：血統（父・母父の芝ダート・距離の成績）、JRAのクッション値・含水率、今回の相手との直接対決、展開（ペース）の予想。
- 同じ2頭が半年以内に再戦して、前回と同じ馬が先着する割合は64%です。当日のぶれは、メンバー内の実力差と同じくらい大きいということです。実力を完全に知っていても、1位の馬が3着以内に来るのは66%前後、上位5頭に3頭そろうのは34%前後が目安です。

## 7. 注意

- この式は、本命の式（1位63%）より当たりが落ちます。人気順の代わりにはなりません。「オッズと関係なく、数字だけで見るとどの馬がどのくらいか」と、「このレースは堅いか荒れそうか」を出す物差しです。
- 数字は2024〜2026年の平均です。1レースごとの的中を約束するものではありません。
- 以前の「手で使える式」（claude/three-cards-formula-guide.md、標準化して足す式）は 1位57.2%・上位5頭に28.0%で、当たりはほぼ同じです。フェルミ式のほうが手で計算しやすい形です。

## 8. メインレース（11R）は倍率を弱める

メインレースでは、この式は強気すぎます。2024〜26年のメインレースで、式が上位3頭に付けた確率の平均は45.8%、実際は40.9%でした。
2011〜23年のデータで合わせ直すと、メインレースだけ「オッズを0.79乗する」とちょうど合います（ほかのレースは0.96乗で、ほぼそのまま）。

- 使い方：§3のコードで `top3_probabilities(horses, power=0.79)`。
- 2024〜26年のメインレースで確かめた結果：上位3頭の見立て 41.0%・実際 40.9%。
- 馬の順位は変わりません。変わるのは確率の数字と堅さ指数です（メインレースの堅さ指数は平均1.93→1.77に下がります）。§5の表は補正なしの値で作ってあるので、補正後の堅さ指数を§5の表に当てはめないでください。メインレースは下の§9の「5点の確率の合計」で見ます。

## 9. 3連複5点：同時確率から選ぶ

各馬の「3着以内の確率」を3頭ぶん掛けても、3連複の確率にはなりません（3頭が同時に入る確率は、1頭ずつの確率の積より小さく、組どうしで合計も合いません）。
そこで、全部の組の確率を足すと1になり、どの馬の「その馬を含む組の合計」も元の3着内確率に一致するように、全組の確率を作ります（1着を強さに比例して引き、残りから2着、3着を引く考え方）。その中で確率の高い5組を買います。

的中率を最大にするだけなら、この「確率の高い順に5組」が最善です（3連複は1レースに当たりが1組だけなので、5組の的中率は5組の確率の合計そのものです）。

```python
import itertools
import numpy as np

def _ordered(v):
    S = v.sum(); P1 = v / S
    P2 = P1[:, None] * v[None, :] / (S - v[:, None]); np.fill_diagonal(P2, 0)
    den = S - v[:, None, None] - v[None, :, None]
    P3 = P2[:, :, None] * v[None, None, :] / np.where(den > 1e-12, den, np.inf)
    ix = np.arange(len(v)); P3[ix, ix, :] = 0; P3[ix, :, ix] = 0; P3[:, ix, ix] = 0
    return P1, P2, P3

def top_trios(probs, k=5):
    """probs: top3_probabilities の戻り値 {馬番: 3着内確率}。確率の高い3連複を k 組返す。[((馬番,馬番,馬番), 確率), ...]"""
    nums = sorted(probs); p = np.clip(np.array([probs[i] for i in nums], float), 1e-4, 1 - 1e-4)
    target = np.log(p / (1 - p)); lv = target.copy()
    for _ in range(40):                        # 組から計算し直した3着内確率が、入力と一致するまで強さを直す
        P1, P2, P3 = _ordered(np.exp(lv - lv.max()))
        m = np.clip(P1 + P2.sum(axis=0) + P3.sum(axis=(0, 1)), 1e-6, 1 - 1e-6)
        lv += 0.8 * (target - np.log(m / (1 - m)))
    _, _, P3 = _ordered(np.exp(lv - lv.max()))
    T = sum(P3.transpose(a) for a in itertools.permutations(range(3)))
    out = [((nums[i], nums[j], nums[k_]), float(T[i, j, k_])) for i, j, k_ in itertools.combinations(range(len(nums)), 3)]
    return sorted(out, key=lambda x: -x[1])[:k]
```

5組の確率の合計は、そのまま「5点のどれかが当たる確率」として読めます。2024〜26年のメインレース783件（§8の補正後）で確かめた結果：

| 5点の確率の合計 | レース数 | 実際に当たった率 |
|---|---|---|
| 10%以下 | 346 | 7% |
| 10〜15% | 269 | 12% |
| 15〜20% | 111 | 23% |
| 20%超 | 57 | 40% |

本命の式で同じことをすると、5点の見立ての平均25.3%に対して実際25.8%（メインレースは17.8%に対して17.6%）で、よく合っています。

## 11. 追加の検証（2026-11-14）

**指数を1つ抜いたときの悪化**（13項目から1つ外して合わせ直し。数字が大きいほど、その指数にしかない情報が多い）

| 外した指数 | 1位の馬の3着内率 | 上位5頭にそろう率 |
|---|---|---|
| 騎手 | −0.9pt | −1.0pt |
| 前走の着順 | −0.3pt | −0.7pt |
| 1走あたり賞金 | −0.4pt | −0.3pt |
| 調教師 | −0.6pt | −0.2pt |
| クラスの下がり幅 | −0.8pt | −0.1pt |
| 近5走の着順／着差 | ほぼ0 | −0.3pt／−0.2pt |
| 休養・馬体重・キャリア | −0.2pt | ほぼ0 |
| 上がり順位 | −0.4pt | ＋0.4pt |

近5走の着順と着差は互いに似た情報なので、片方を抜いてももう片方が埋めます。似た指数を両方入れても確率が強気になりすぎていないことは、§4の確率の合い方で確かめています（強気になるのはメインレースだけで、§8で直します）。

**条件別の確率の合い方**（式の上位3頭：見立て → 実際）

| 条件 | 見立て | 実際 | 1位の馬の3着内率 | 上位5頭にそろう率 |
|---|---|---|---|---|
| 2歳戦 | 42.7% | 48.3% | 58.5% | 30.2% |
| 重賞 | 44.8% | 40.9% | 50.1% | 17.9% |
| ダート1400m以下 | 44.8% | 46.5% | 55.8% | 23.5% |
| 芝2000m以上 | 47.6% | 50.2% | 60.3% | 31.1% |
| メインレース（補正前） | 45.8% | 40.9% | 50.5% | 18.3% |

2歳戦は式が控えめ（実際のほうが5pt以上高い）、重賞とメインレースは強気です。年齢・キャリア・休養の倍率そのものは条件別に見ても大きくずれていません（例：重賞の7歳以上は見立て10.4%・実際13.1%）。

**実力を完全に知っていた場合の上限**（§6の66%・34%）は、「馬の実力は半年変わらず、当日のぶれはどの馬も同じ大きさ」という仮定を置いた見積もりです。確かな天井ではなく目安です。
